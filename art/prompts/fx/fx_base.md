FX Base Prompt

Read First:

- /art/STYLE.md
- /art/AGENTS.md

Purpose:

Base generation template for effect assets used in Mahjong Three Kingdom TD.

This template defines the visual foundation for gameplay FX, skill effects, Mahjong combination effects, reward flashes, and combat feedback effects.
Specific effect identity and gameplay role must come from queue tasks.

---

Style Requirements

Visual Style:

- Cute Premium
- Stylized 2.5D-compatible effect language
- Tactical readability first
- Reward clarity
- Memorable but controlled impact

Must match all STYLE.md requirements.

---

FX Philosophy

Effects should feel:

- Satisfying
- Tactical
- Memorable
- Clean

Priority must support STYLE.md:

- Hu as highest spectacle
- Gang as strong impact
- Peng as fast confirmation

Avoid:

- Particle spam
- Flash overload
- Unreadable explosions
- Dark muddy visual noise

---

Rendering Requirements

Rendering:

- Clean shape language
- Soft glow control
- Readable silhouette
- Strong visual hierarchy
- Clear gameplay feedback

Avoid:

- Photoreal VFX
- Excessive bloom
- Chaotic particle clouds
- Low-contrast energy shapes

---

Background Rules

Required:

- Transparent background
- PNG-ready asset
- Fully isolated effect asset

Forbidden:

- White background
- Colored background
- Scene background
- Character background plate

Asset must require ZERO manual background removal.

---

Composition Rules

- Single effect asset or tightly unified effect cluster only
- Centered composition preferred
- Readable shape at gameplay scale
- Strong negative space when needed

Avoid:

- Full scene compositions
- Mixed unrelated effects
- Background decoration not part of the effect

---

Export Rules

Output Type:

- Individual asset
- Game-ready
- Transparent PNG compatible

Asset should be suitable for:

- Battle feedback
- Skill activation
- Mahjong combo confirmation
- Reward moments
- UI effect overlays

No post-processing required.

---

Consistency Rules

Must follow:

- STYLE.md
- AGENTS.md
- Readability-first FX rules
- Project-wide visual language

No style drift allowed.

---

Queue Integration

FX identity will be supplied by queue tasks.

Examples:

- fx_hu_super_v1
- fx_peng_confirm_v1
- fx_wei_skill_slash_v1

This template only defines the visual foundation.
