UI Base Prompt

Read First:

- /art/STYLE.md
- /art/AGENTS.md

Purpose:

Base generation template for UI assets used in Mahjong Three Kingdom TD.

This template defines the visual foundation for UI elements, panels, buttons, frames, badges, and decorative interface components.
Specific screen purpose and component identity must come from queue tasks.

---

Style Requirements

Visual Style:

- Cute Premium
- Mobile readable
- Three Kingdom inspired decorative language
- Warm polished materials
- Clear gameplay readability

Must match all STYLE.md requirements.

---

UI Language

UI Materials:

- Wood
- Gold
- Warm decorative frame
- Rounded edge

UI should feel:

- Premium
- Friendly
- Tactical
- Clean

Avoid:

- Sci-fi panels
- Flat modern minimalism
- Metallic future interface
- Childish toy UI
- Visual clutter

---

Rendering Requirements

Rendering:

- Clean silhouette
- Soft shading
- Mild material depth
- Readable borders
- Clear interaction hierarchy

Avoid:

- Photorealism
- Heavy texture noise
- Overly ornate unreadable frames
- Dark muddy contrast

---

Background Rules

Required:

- Transparent background
- PNG-ready asset
- Fully isolated UI element

Forbidden:

- White background
- Colored background
- Scene background
- Character illustration background

Asset must require ZERO manual background removal.

---

Composition Rules

- Single UI component or tightly grouped component set only
- Clean edge definition
- Usable negative space for text or icons when relevant
- Readable at mobile landscape scale

Avoid:

- Full mockup screens
- Busy compositions
- Decorative clutter that harms usability

---

Export Rules

Output Type:

- Individual asset
- Game-ready
- Transparent PNG compatible

Asset should be suitable for:

- Home UI
- Battle UI
- Result UI
- Upgrade UI
- Economy UI

No post-processing required.

---

Consistency Rules

Must follow:

- STYLE.md
- AGENTS.md
- Faction accent rules when requested
- Cute Premium UI language
- Project-wide visual language

No style drift allowed.

---

Queue Integration

UI identity will be supplied by queue tasks.

Examples:

- ui_home_main_panel_v1
- ui_battle_skill_button_v1
- ui_result_rank_badge_v1

This template only defines the visual foundation.
